# BXL-006 Code Review

Status: RESOLVED

## Review Result

- **P2／批次上傳缺少必要檔案時回傳 422。**

## Implementation Plan

§5.2 及 §7 BXL-006 要求區分 FastAPI 預設驗證與 Excel 請求的 400 錯誤；需求 §2-5-3 將缺少必要欄位列為 400。

## Existing Implementation

`src/controllers/product_controller.py:168` 直接使用 `file: UploadFile = File(...)`，缺少 multipart `file` 時由 FastAPI 回傳預設驗證錯誤。

## Review Issue

實際呼叫 `POST /productController/batchProducts` 而未附檔，得到 HTTP 422、`Message: Validation error`；未符合批次請求資料缺失時的 400 契約。

## Expected Behavior

缺少必要上傳檔案時回傳專案標準錯誤封套與 HTTP 400；有效檔案仍按副檔名、表頭及資料列規則處理。

## Suggested Area To Fix

檢查批次路由的上傳驗證邊界與控制器測試，避免變更其他端點的全域驗證行為。

## Resolution

Status: RESOLVED（2026-10-14 複審）。批次路由將缺檔案轉為 `ProductBatchError`，控制器測試確認標準錯誤封套及 HTTP 400；未改動全域驗證處理。
