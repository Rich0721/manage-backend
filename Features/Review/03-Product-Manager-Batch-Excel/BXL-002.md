# BXL-002 Code Review

Status: OPEN

## Review Result

- **P1／舊快取的庫存值可能錯誤。**

## Implementation Plan

§7 BXL-002 要求部署期遇到缺少 `stock` 的舊商品快照時，從資料庫重建，不將缺失欄位默認為真實庫存 0。

## Existing Implementation

`src/repositories/product_cache_repository.py:308` 使用 `int(value.get("stock", 0))` 還原快照；`ProductService.__get_all_products()` 會直接回傳這份快照。

## Review Issue

若舊快照在新程式部署時仍留於 Redis，而資料庫的庫存已有非零更新，查詢與 Excel 匯出會得到 0。單筆更新未提供 `stock` 時，也會將這個 0 寫回資料庫。

## Expected Behavior

缺少 `stock` 的商品快照必須失效並從資料庫重建，單筆更新須保留資料庫中的原有庫存。

## Suggested Area To Fix

檢查商品快取反序列化與冷載入路徑，增加缺欄位快照及單筆更新的回歸測試。

## Resolution

Status: OPEN；待 Programmer 修正後複審。
