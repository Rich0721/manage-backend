# HDR-002 Code Review

Status: RESOLVED

## Task ID

HDR-002

## Review Result

Code Review 通過。User Manager protected routes 只從實際 HTTP `Uid`、`Authorization` headers 建立授權內容，所有成功 response 也會同步實際 HTTP Header 與 JSON `header`。

## Implementation Plan

- protected request 使用實際 HTTP Header 授權。
- response 提供 `Status`、`Message`，適用時提供 `Uid`、`Authorization`。
- JSON `body` 僅包含 `info`，JSON `header` 提供可讀的對應值。
- OpenAPI 描述 response headers。

## Existing Implementation

- Controller 邊界使用 FastAPI `Header` 解析授權資料，再建立內部 `AuthorizationObject`。
- register、login、logout、getUsers、updatePermission 都會設定 response headers。
- 非 ASCII `Message` 在 HTTP Header 使用 UTF-8 percent encoding，JSON 保留可讀文字。
- Controller tests 驗證 Header 優先、舊 body auth 被拒絕與 OpenAPI 文件。

## Review Issue

未發現需要修正的 Review Issue。

## Expected Behavior

JSON 中偽造的授權資料不得影響驗證；授權資訊與結果狀態應由實際 HTTP Header 傳遞。
